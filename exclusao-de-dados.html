Solicitação de exclusão de dados

Você pode solicitar a exclusão dos dados fornecidos ao Teste de Perfil de Inteligência e Carreira seguindo estas etapas:

  1. Envie uma mensagem para o WhatsApp +55 22 99820-0315.
  2. Escreva: “Solicito a exclusão dos meus dados do Teste de Perfil”.
  3. Informe o telefone ou e-mail usado no cadastro para que possamos localizar os dados.

Poderemos solicitar confirmação de identidade para impedir a exclusão indevida dos dados de outra pessoa. Após a validação, os dados serão removidos ou anonimizados dos sistemas utilizados pelo teste, ressalvadas informações cuja conservação seja exigida por lei ou necessária para o exercício de direitos.
